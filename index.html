      클라우드 동기화

      Firebase에 연결하면 로그인한 기기 어디서든 작업을 이어서 할 수 있어요.

      js/config.js에 설정이 들어 있어서 모든 기기에서 자동으로 켜져 있어요.
      Firebase 준비하기 (처음 한 번, 10분)
      1. Firebase 콘솔에서 프로젝트를 만들어요 (무료 Spark 요금제로 충분해요).
      2. 빌드 → Authentication → 시작하기 → 로그인 방법에서 "이메일/비밀번호"를 켜요.
      3. 빌드 → Firestore Database → 데이터베이스 만들기 (위치는 asia-northeast3 서울 추천, 프로덕션 모드).
      4. Firestore의 "규칙" 탭에 아래 규칙을 붙여넣고 게시해요. 로그인한 본인 작업만 읽고 쓸 수 있게 막아줘요.
      5. 톱니바퀴 → 프로젝트 설정 → 일반에서 "웹 API 키"와 "프로젝트 ID"를 복사해 위에 넣어요.
      
        
      여러 기기에서 설정 없이 쓰려면 js/config.js 파일에 같은 값을 적어 두세요.
