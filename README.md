# Custorming

휴대폰 화면 틀 안에 **헤더, 메시지 창, 버튼 같은 오브젝트를 마음대로 조합·배치**해서
나만의 앱을 만들고 꾸미는 비주얼 앱 빌더입니다.

설치나 빌드 없이 `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.
처음 열면 3단계 시작 안내가 나오고, 할 일 앱(MyTasks) 예제가 열린 상태로 시작합니다.

## 사용 방법

1. **오브젝트 놓기**: 왼쪽 팔레트에서 오브젝트를 휴대폰 화면으로 끌어다 놓거나 클릭합니다.
2. **배치하기**: 오브젝트를 끌어서 옮기고, 모서리 핸들로 크기를 바꿉니다.
   캔버스 오른쪽 위 "자석"을 켜면 8px 격자와 다른 오브젝트의 가장자리·가운데에 맞춰 붙습니다.
   휴대폰 위쪽의 `− 100% +`로 확대/축소하고, 가운데 숫자를 누르면 화면에 맞춥니다.
3. **꾸미기**: 블록을 선택하면 오른쪽 속성 패널에서 내용·동작·모양·글자를 바꿀 수 있습니다
   (색상 견본, 슬라이더, 정렬 버튼). 빈 곳을 누르면 화면 배경과 앱 전체 테마(대표 색, 글꼴 등)를 바꿀 수 있습니다.
4. **화면 여러 개**: 왼쪽 "화면"에서 화면을 추가하고, 버튼·목록·카드·탭 바로 화면 사이를 이동하게 만듭니다.
5. **미리보기**: `▶ 미리보기`에서 실제 앱처럼 눌러봅니다. 메시지 입력창에 입력하면 메시지 창에 올라가고 자동 답장도 옵니다.
   화면이 바뀔 때 부드럽게 움직입니다: 다른 화면으로 가면 오른쪽에서 밀려 들어오고, 뒤로 가면 반대로 빠지며, 탭 전환과 로그인 뒤 이동은 겹쳐지듯 바뀝니다.
   빈 곳을 누른 뒤 속성의 **화면 전환 효과**에서 `밀어내기 / 페이드 / 확대 / 없음`을 고를 수 있습니다. (내보낸 앱에도 그대로 적용되고, 기기의 "동작 줄이기"가 켜져 있으면 짧은 페이드만 보여줍니다.)
   **휴대폰 기종 고르기**: 상단의 기종 선택(또는 화면 빈 곳을 누른 뒤 속성의 **휴대폰 틀**)에서 기종을 고르면 화면 크기와 틀 모양이 그 기종에 맞게 바뀝니다.
   iPhone 15 Pro/Pro Max(다이내믹 아일랜드), iPhone 14 · 13 mini(노치), iPhone SE(홈 버튼), Galaxy S24 · S24 Ultra · Z Flip5, Pixel 8(펀치홀), iPad mini · Galaxy Tab S9를 지원하고,
   `직접 입력…`으로 원하는 크기(예: `400x860`)도 정할 수 있습니다. 틀 색(그래파이트, 블랙, 실버, 골드, 블루, 핑크)도 고를 수 있습니다.
   기종을 바꾸면 가로로 꽉 찬 블록은 새 너비에, 아래에 붙은 블록(탭 바 등)은 새 아래쪽에 맞춰집니다.
6. **내보내기**: `더보기 → 앱 내보내기`를 누르면 혼자 실행되는 HTML 파일 하나가 만들어집니다. 휴대폰에서 열어도 동작합니다.

작업 내용은 브라우저에 자동 저장됩니다(상단의 "자동 저장됨" 표시). `저장`으로 프로젝트 파일(JSON)을 받아두고
`더보기 → 파일 열기`로 다시 불러올 수 있으며, 내보낸 HTML 앱 파일을 불러와 다시 편집할 수도 있습니다.

### 내 앱 (앱 여러 개)

상단의 **`내 앱`** 버튼을 누르면 만든 앱 목록이 미리보기 그림과 함께 나옵니다.

- **새 앱 만들기**: 템플릿(할 일 앱, 빈 앱, 메신저 앱, 로그인 + 홈)에서 새 앱을 만듭니다. `더보기`의 템플릿도 지금 작업을 지우지 않고 새 앱으로 만듭니다.
- 카드를 누르면 그 앱을 열고, 카드 아래 버튼으로 **이름 바꾸기 · 복제 · 삭제**를 할 수 있습니다.
- `파일 열기`로 불러온 프로젝트/HTML 앱도 새 앱으로 목록에 추가됩니다.
- 게스트와 계정마다 목록이 따로 있습니다. 클라우드 동기화를 켜면 목록 전체가 다른 기기에도 보이고,
  다른 기기에서 만들거나 이름을 바꾸거나 지운 앱도 반영됩니다. (아직 이 기기에 내려받지 않은 앱은 "클라우드에 있어요"로 표시되고, 누르면 받아서 엽니다.)
- 예전 버전에서 저장한 작업은 처음 열 때 목록의 첫 앱으로 자동으로 옮겨집니다.

### 만든 앱에 로그인 넣기

내보낸 앱을 쓰는 사람도 회원가입·로그인할 수 있습니다. (예제: `더보기 → 할 일 앱`, `로그인 + 홈`)

1. **로그인 폼** 블록(왼쪽 `입력` 그룹)을 화면에 놓습니다. 로그인 + 회원가입 탭, 로그인만, 회원가입만 중에서 고를 수 있습니다.
2. 로그인해야 하는 화면을 고르고, 빈 곳을 누른 뒤 속성에서 **"로그인해야 볼 수 있는 화면"**을 켭니다.
   게스트가 그 화면에 가려고 하면 로그인 화면으로 안내되고, 로그인하면 원래 가려던 화면으로 돌아갑니다.
   (로그인이 필요 없는 화면은 게스트도 자유롭게 쓸 수 있어서 "먼저 둘러보고 나중에 가입"하는 앱을 만들 수 있습니다.)
3. 버튼 동작 **"로그인 화면으로"**, **"로그아웃"**으로 원할 때 로그인/로그아웃하게 합니다.
4. 블록마다 **보이는 때**를 `항상 / 로그인 전 / 로그인 후`로 정할 수 있습니다. (예: "로그인" 버튼은 로그인 전에만)
5. 글자에 **`{이름}`**, **`{이메일}`**을 쓰면 로그인한 사람 정보로 바뀝니다. 게스트에게는 `{이름}`이 "게스트"로 보입니다.

캔버스 왼쪽 위 `로그인 전 / 로그인 후`로 두 상태의 화면을 나눠서 보며 편집할 수 있습니다.

#### 계정 저장 위치: 이 기기만 / Firebase (여러 기기)

화면 빈 곳을 누른 뒤 속성의 **앱 사용자 로그인 → 계정 저장 위치**에서 고릅니다.

- **이 기기만** (기본): 가입 정보가 앱을 쓰는 사람의 기기에만 저장됩니다(비밀번호는 해시해서 보관). 설정이 필요 없지만 다른 기기와 공유되지 않습니다.
- **Firebase · 여러 기기**: [Firebase Authentication](https://firebase.google.com/docs/auth)에 계정이 저장되어, 한 번 가입하면 어느 기기에서든 같은 이메일·비밀번호로 로그인됩니다. 이름도 계정에 저장되어 다른 기기에서 보이고, "비밀번호를 잊으셨나요?"로 재설정 메일도 보낼 수 있습니다.

Firebase 연결 방법 (무료):

1. [Firebase 콘솔](https://console.firebase.google.com/)에서 프로젝트를 만듭니다.
2. 빌드 → **Authentication → 시작하기**, 로그인 방법 탭에서 **이메일/비밀번호**를 사용 설정합니다.
3. 톱니바퀴 → 프로젝트 설정 → 일반에서 **웹 API 키**를 복사해 Custorming에 붙여넣고 **연결 확인**을 누릅니다.
   (웹 앱이 없다면 `</>` 아이콘으로 웹 앱을 먼저 추가하세요.)
4. 미리보기에서 가입해 보면 Firebase 콘솔의 Users 탭에 사용자가 나타납니다.

Firebase SDK 없이 [Auth REST API](https://firebase.google.com/docs/reference/rest/auth)를 직접 호출하므로 내보낸 HTML 파일 하나로 동작합니다.
웹 API 키는 앱에 포함돼도 되는 공개용 키지만, 필요하면 Google Cloud 콘솔에서 키 사용처를 제한할 수 있습니다.

### 로그인 / 회원가입 · 여러 기기에서 이어서 작업하기 (선택)

로그인하지 않아도 게스트로 모든 기능을 쓸 수 있습니다. 원할 때 오른쪽 위 `로그인` 버튼으로 회원가입하거나 로그인하세요.

- **회원가입**: 지금 만들던 작업이 새 계정에 그대로 저장됩니다.
- **로그인**: 계정에 저장된 작업이 열립니다(저장된 작업이 없으면 지금 작업을 계정에 저장).
- **로그아웃**: 오른쪽 위 프로필 동그라미 → 로그아웃. 게스트 작업으로 돌아갑니다.

기본으로는 계정이 **이 브라우저에만** 저장됩니다. **클라우드 동기화**를 켜면 Firebase 계정으로 로그인하고,
작업이 Firestore에 저장되어 다른 기기에서 같은 계정으로 로그인하면 그대로 이어서 작업할 수 있습니다.

#### 클라우드 동기화 켜기

1. [Firebase 콘솔](https://console.firebase.google.com/)에서 프로젝트를 만듭니다 (무료 Spark 요금제로 충분).
2. **Authentication → 시작하기 → 로그인 방법**에서 "이메일/비밀번호"를 켭니다.
3. **Firestore Database → 데이터베이스 만들기** (프로덕션 모드, 위치는 `asia-northeast3` 서울 추천).
4. Firestore **규칙** 탭에 아래 규칙을 붙여넣고 게시합니다. 로그인한 본인의 작업만 읽고 쓸 수 있습니다.

   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /users/{uid}/{document=**} {
         allow read, write: if request.auth != null && request.auth.uid == uid;
       }
     }
   }
   ```

5. 프로젝트 설정 → 일반에서 **웹 API 키**와 **프로젝트 ID**를 복사해 넣습니다. 두 가지 방법이 있습니다.
   - **모든 기기에 한 번에**: `js/config.js`의 `apiKey`, `projectId`에 적어 둡니다. (이 에디터를 웹에 올려서 쓸 때 추천)
   - **기기마다**: 에디터의 `더보기 → 클라우드 동기화 설정`에 넣고 `연결 확인` → `저장하고 켜기`.

동기화 방식:

- 작업은 바뀔 때마다 이 기기에 먼저 저장되고, 1초쯤 뒤 클라우드에 올라갑니다. 상단 표시가 "클라우드에 저장됨"으로 바뀝니다.
- 에디터를 켜거나 창으로 돌아오면, 다른 기기에서 바뀐 내용을 자동으로 불러옵니다.
- 인터넷이 끊기면 "오프라인 · 이 기기에만 저장됨"으로 표시하고, 다시 연결되면 올립니다.
- 두 기기에서 동시에 고쳐서 버전이 엇갈리면, 어느 쪽 작업을 남길지 물어봅니다 (몰래 덮어쓰지 않음).
- 앱마다 `users/{uid}/projects/{앱 id}` 문서 하나에 저장됩니다. 문서 크기 한도(1MB)는 앱 하나 기준이라, 한 앱에 큰 이미지를 많이 올리면 저장이 거부될 수 있습니다.

### 단축키

| 키 | 동작 |
| --- | --- |
| `Delete` / `Backspace` | 선택한 오브젝트 삭제 |
| `Ctrl+Z` / `Ctrl+Shift+Z` (`Ctrl+Y`) | 실행 취소 / 다시 실행 |
| `Ctrl+C` / `Ctrl+V` | 복사 / 붙여넣기 (다른 화면에도 가능) |
| `Ctrl+D` | 복제 |
| 방향키 (`Shift` + 방향키) | 1px (10px) 이동 |
| `Ctrl+S` | 프로젝트 파일 저장 |
| `Esc` | 선택 해제 / 미리보기 닫기 |

## 오브젝트

| 분류 | 오브젝트 | 설명 |
| --- | --- | --- |
| 기본 | 버튼, 이미지, 텍스트, 카드, 목록, 헤더 | 버튼 동작: 화면 이동 / 뒤로 / 알림 / 메시지 보내기 / 링크 열기 |
| 데이터 | 체크리스트, 통계 카드, 프로필 | 체크리스트는 `x `로 완료 표시, 미리보기에서 눌러서 체크 |
| 입력 | 입력 칸, 스위치 | 일반·비밀번호·이메일·숫자 입력, 켜고 끄는 스위치 |
| 메시지 | 메시지 창 | `이름: 내용` 형식의 대화, 자동 답장(`{메시지}` = 보낸 내용) |
| | 메시지 입력창 | 같은 화면의 메시지 창으로 메시지 전송 |
| 레이아웃 | 섹션, 구분선 | 배경 박스, 선 |
| | 탭 바 | `home 홈 = 홈` 형식으로 아이콘·탭 이름·이동할 화면 지정 |


아이콘 이름: `home list bell user chat users settings search heart star calendar plus more cart` (이모지도 됩니다)

## 구조

```
index.html          에디터 화면
css/editor.css      에디터 스타일
js/runtime.js       프로젝트(JSON)를 실제 화면으로 그리고 동작시키는 런타임
                    (에디터 캔버스, 미리보기, 내보낸 앱이 모두 공유)
js/components.js    오브젝트 종류별 기본값과 속성 패널 항목
js/templates.js     시작 템플릿 (할 일 앱, 빈 앱, 메신저 앱, 로그인 + 홈)
js/devices.js       휴대폰 기종별 크기와 틀 모양
js/config.js        클라우드 동기화용 Firebase 설정 (선택)
js/auth.js          선택형 계정 (이 브라우저 또는 Firebase Authentication)
js/cloud.js         Firestore에 작업 저장·불러오기 (REST API)
js/editor.js        배치·선택·크기 조절·실행 취소·저장/내보내기
```

프로젝트는 아래와 같은 JSON 하나로 표현됩니다.

```json
{
  "name": "나의 메신저",
  "size": { "w": 360, "h": 740 },
  "theme": { "primary": "#5b5bf7", "bg": "#ffffff", "text": "#1d1d1f", "font": "system" },
  "startScreen": "s1",
  "screens": [
    { "id": "s1", "name": "채팅방", "bg": "", "components": [
      { "id": "c1", "type": "header", "x": 0, "y": 0, "w": 360, "h": 56, "props": { "title": "민지" } }
    ] }
  ]
}
```

새 오브젝트를 추가하려면 `js/components.js`에 정의를, `js/runtime.js`의 `renderers`에 그리는 함수를 추가하면 됩니다.
